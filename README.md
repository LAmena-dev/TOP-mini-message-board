# TOP-mini-message-board
A [mini-message-board](https://www.theodinproject.com/lessons/node-path-nodejs-mini-message-board) using Express and EJS.
React-frontend branch uses React as the frontend framework.

## Technology used
* React
* CSS
* Node + Express.js
* PostgreSQL
* Render (for hosting)

## Features
* Reading messages
* Creating messages
* Deleting messages
* Updating messages (to be implemented in React-frontend branch)
